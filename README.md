# esp32_diy_lmi
DIY LMI for crane using dual esp32


This is an attempt to create a DIY LMI (Load Moment Indicator) for an old crane I have, more specifically a PM 10022 mounted to a DAF LF55.220 15T truck.
My idea is to use simple, cost effective equipment.
I have a chinese branded proportional remote bought from aliexpress that has basic control over the crane's levers but it lacks any electronics to monitor anything on the crane and the crane is old tech without any electronics or hydraulic cut offs.
Plan in the end is to have something like a LMI system with a display attached to the crane's remote control to be able to monitor the stability of the truck, the weight on the hook, the lenght of the extension together with a tilt detection system to help maintaining the truck on the ground without it tipping off.



1st step of the project will be tested on web page hosted on the receiver
